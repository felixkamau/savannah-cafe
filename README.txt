Savanna Brew Café Website
========================

Project Structure
-----------------
- index.html      : Home page (hero section, welcome text, 3 featured cards, CTA buttons)
- about.html      : About Us page (two-column story, owner quote, values list)
- menu.html       : Menu page (3 semantic tables: Hot Drinks, Cold Drinks, Bakery & Snacks)
- gallery.html    : Photo Gallery (responsive 4 -> 2 -> 1 CSS Grid with 8 captioned figures)
- contact.html    : Contact & Reservations (accessible form, opening hours table, embedded map)
- events.html     : Bonus page highlighting monthly community events
- css/style.css   : Single external stylesheet using CSS variables, Flexbox, Grid, and media queries
- images/         : All required images (logo.png, hero.jpg, about-owner.jpg, latte.jpg,
                    cappuccino.jpg, croissant.jpg, gallery-1.jpg to gallery-8.jpg)
